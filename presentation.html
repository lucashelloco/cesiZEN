🐘

PostgreSQL — atouts décisifs pour CesiZen

Schéma strict avec FK garantissant l'intégrité (auteurId → User, userId → User). Enums Prisma (Role, TypeContenu) natifs. Contraintes d'unicité composées (nom, isPreset).

⚡

Neon — PostgreSQL serverless

Branching de base de données (dev/prod isolés), scale-to-zero, intégration Vercel native, tier gratuit généreux. DATABASE_URL + DIRECT_URL pour les migrations Prisma.

❌

MongoDB écarté

Données CesiZen sont relationnelles (User → Contenus, User → Exercices). Un schéma NoSQL documentaire n'apporte aucun avantage et perd les FK, les Enums et les contraintes d'unicité.

Progressive Web App & Mobile

next-pwa · Workbox

CesiZen est une Progressive Web App installable sur mobile et desktop. Elle fonctionne hors-ligne pour les contenus déjà consultés et offre une expérience native.

⚙️ Fonctionnalités PWA

  • ✓Service Worker — mise en cache automatique (Workbox)
  • ✓Manifest.json — icônes, couleurs, orientation, display standalone
  • ✓Cache des assets — chargement instantané au retour
  • ✓Installation — bouton "Ajouter à l'écran d'accueil" sur mobile et Chrome
  • ✓Online/offline — rechargement automatique à la reconnexion

📐 Responsive Design

  • ✓Mobile-first — viewport 375 px testé (Playwright Mobile Chrome)
  • ✓Sidebar admin en menu hamburger sur mobile
  • ✓Timer circulaire SVG adaptatif
  • ✓Tables admin avec colonnes masquées en mobile (hidden md:table-cell)

🌙 Thème clair / sombre

  • ✓next-themes — bascule instantanée sans rechargement
  • ✓Persistance en localStorage
  • ✓Toggle accessible (aria-label) dans nav et sidebar admin
  • ✓Tokens CSS OKLCH — contraste garanti dans les deux thèmes
